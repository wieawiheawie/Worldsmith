# Worldsmith roadmap

This roadmap describes intended milestones, not a claim that these features are already implemented.

## Milestone 0 — Editor shell (current)

- [x] Establish React, TypeScript and Vite application
- [x] Add top-level Scene, Model, Materials, Animation, UI, Logic, Audio and Assets workspaces
- [x] Add shared editor layout: toolbar, tool rail, explorer, viewport, inspector and bottom dock
- [x] Add workspace-specific visual review layouts
- [x] Add basic navigation, filtering, selection, command palette and preview-state controls
- [ ] Review visual direction and revise the shell
- [ ] Confirm build in GitHub Actions and Codespaces

## Milestone 1 — Project and document foundation

- [ ] Project create/open/save flow
- [ ] Versioned project document format
- [ ] Scene graph and entity/component data model
- [ ] Asset database and dependency references
- [ ] Local persistence, import/export and recovery
- [ ] Unified command and undo/redo system

## Milestone 2 — First real scene editor

- [ ] Interactive 2D/3D viewport
- [ ] Real object creation and selection
- [ ] Transform gizmos and editable properties
- [ ] Hierarchy operations
- [ ] Camera and lighting controls
- [ ] Functional play/stop preview lifecycle

## Milestone 3 — Creative studios

- [ ] UI layout and widget authoring
- [ ] 2D sprite and tilemap authoring
- [ ] Mesh modelling foundations
- [ ] Texture painting and material authoring
- [ ] Animation timeline and keyframes
- [ ] Visual logic and scripting integration

## Milestone 4 — Game systems

- [ ] Physics and collision
- [ ] Audio and mixer
- [ ] Character controllers and animation graphs
- [ ] UI runtime and input
- [ ] Particles and effects
- [ ] AI and navigation

## Milestone 5 — Publishing and extensibility

- [ ] Portable web game builds
- [ ] Self-hostable editor builds
- [ ] Documented plugin API
- [ ] Community extensions
- [ ] Optional collaboration and cloud services
